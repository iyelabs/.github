# Security policy

This policy applies to every repository in the [iyelabs](https://github.com/iyelabs) organization that does not publish its own.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

If the affected repository has private vulnerability reporting enabled, use **Security → Report a vulnerability** on that repository. Otherwise, email [info@iyelabs.com](mailto:info@iyelabs.com) with the subject line `Security report`.

Include as much of the following as you can:

- the affected repository, component and version or commit
- a description of the issue and its impact
- steps to reproduce or a proof of concept
- any suggested mitigation

## What to expect

We will acknowledge your report, keep you informed while we investigate, and coordinate disclosure with you. Please allow us reasonable time to address the issue before any public disclosure.
